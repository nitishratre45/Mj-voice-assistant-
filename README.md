# MJ Voice Assistant

A Windows-first Hindi / English / Hinglish voice assistant with wake-word listening, app control, web search, screen automation, memory, TTS and optional AI fallback.

## Start

1. Install Python 3.10+.
2. Run:
   ```bat
   start_mj.bat
   ```
3. Say **"MJ"**, then speak a command.

## Useful commands

- "MJ, YouTube kholo"
- "MJ, calculator kholo"
- "MJ, screenshot lo"
- "MJ, volume badhao"
- "MJ, volume kam karo"
- "MJ, mute karo"
- "MJ, desktop dikhao"
- "MJ, computer lock karo"
- "MJ, system status batao"
- "MJ, health check karo"
- "MJ, time kya hai"
- "MJ, aaj ki date kya hai"
- "MJ, Google par Tilak Varma search karo"

## Configuration

Environment variables are supported for Whisper, TTS and network timeouts. Keep API keys out of source control; use environment variables such as `GEMINI_API_KEY`.
