# MJ Part 2 — Brain + Action

Part 2 adds a first intent/action layer on top of Part 1.

Examples:
- YouTube kholo
- YouTube open
- You tube chalao
- Google kholo
- Chrome open
- Notepad kholo
- Calculator chalao
- File Explorer kholo
- Command Prompt kholo

The action layer is intentionally deterministic for safety and reliability.
The larger reasoning/memory/planning system will be added in later parts.

Run:

python mj.py
